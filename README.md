# Retired website repository

**Current source: https://github.com/tim-builds/timbuilds.dev**

All new website issues, pull requests and publishing belong in `tim-builds/timbuilds.dev`. Its `main` builds one Cloudflare Pages project (`timbuilds-site`) for both `timbuilds.dev` and `tim-builds.dev`. The old-source-to-new-mirror workflow is retired; do not copy site changes into this repository.

This repository is retained as read-only history and fallback material. Its files and branches have not been deleted. All former main-line work is contained in the canonical repository; four historical non-ancestral branch heads are separately preserved there under `archive/site/*`. The remaining privacy PR #1 was reconciled and closed as superseded by later approved changes, with its original commit and discussion retained.

The historical GitHub Pages settings and CNAME are deliberately retained while migration acceptance and WWW cleanup remain open. Archiving is reversible; unarchive before an approved emergency edit/rebuild. Do not remove the fallback merely because the two main domains now use Cloudflare. Read canonical `HOSTING.md` and issue #20 for the current status and rollback boundaries.

Original README/desktop notes are in `docs/historical-readme.md`; they are not operational instructions. Other old hosting/migration prose in this read-only repository is superseded by the canonical README, AGENTS and HOSTING documents. The separate native OpenHoops implementation, email/Supabase configuration, operator research, and private Candystand runtime are not changed by this retirement.
